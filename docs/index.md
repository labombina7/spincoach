# Spin Coach

App personal de iOS para sesiones de spinning: música de tu Spotify ajustada por BPM a cada bloque del entrenamiento y un coach de voz que te guía.

- [Producto](producto.md) · [Entrenamiento](entrenamiento.md) · [Arquitectura](arquitectura.md) · [Plan](plan.md)
- Código y documentación: [github.com/labombina7/spincoach](https://github.com/labombina7/spincoach)

## Créditos

- Song BPM data provided by <a href="https://getsongbpm.com">GetSongBPM.com</a>.
- Datos de tempo también de [ReccoBeats](https://reccobeats.com).
- Música y reproducción a través de [Spotify](https://www.spotify.com).
